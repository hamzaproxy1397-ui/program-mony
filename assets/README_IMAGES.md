# مجلد الصور

## الصور المطلوبة:

### صورة المدير (ceo_image.jpg)
- **الاسم**: محمود عبد الحميد
- **المنصب**: مدير الشركة ورئيس مجلس الإدارة
- **الحجم المطلوب**: 300x300 بكسل
- **الشكل**: دائري مع إطار ذهبي

### تعليمات:
1. استبدل الصورة الافتراضية بصورة المدير الحقيقية
2. تأكد من أن الصورة بجودة عالية
3. الصورة ستظهر بشكل دائري تلقائياً
4. سيتم إضافة إطار ذهبي احترافي
