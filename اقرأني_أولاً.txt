🏢 برنامج ست الكل للمحاسبة
========================================

📋 دليل التشغيل السريع
========================================

🚀 الطريقة الأسهل للتشغيل:
1. انقر نقراً مزدوجاً على "INSTALL_AND_RUN.bat"
2. اتبع التعليمات التي تظهر على الشاشة
3. سيتم تثبيت Python والمكتبات المطلوبة تلقائياً

🔐 بيانات تسجيل الدخول الافتراضية:
- اسم المستخدم: admin
- كلمة المرور: admin

📁 ملفات التشغيل المتاحة:
========================================

🎯 للمبتدئين:
- INSTALL_AND_RUN.bat          ← التثبيت والتشغيل التلقائي
- RUN_ACCOUNTING_SOFTWARE.bat  ← تشغيل البرنامج الكامل
- launch_main_window.bat       ← تشغيل النافذة الرئيسية فقط

🔧 للمطورين:
- quick_diagnostic.py          ← تشخيص سريع للمشاكل
- error_checker_and_fixer.py   ← فحص وإصلاح الأخطاء
- test_simple.py              ← اختبار بسيط للواجهة

📊 ملفات البرنامج الرئيسية:
- main.py                     ← الملف الرئيسي للبرنامج
- START_HERE.py               ← لوحة التحكم المركزية
- run_main_window.py          ← تشغيل النافذة الرئيسية

🛠️ حل المشاكل الشائعة:
========================================

❌ مشكلة: "Python not found"
✅ الحل:
   1. شغل INSTALL_AND_RUN.bat
   2. اختر الخيار 1 أو 2 لتثبيت Python
   3. تأكد من تحديد "Add Python to PATH" أثناء التثبيت

❌ مشكلة: "Module not found"
✅ الحل:
   1. شغل INSTALL_AND_RUN.bat (سيثبت المكتبات تلقائياً)
   2. أو شغل هذا الأمر يدوياً:
      pip install customtkinter pillow numpy

❌ مشكلة: النافذة لا تظهر
✅ الحل:
   1. تحقق من شريط المهام
   2. شغل quick_diagnostic.py للتشخيص
   3. تحقق من ملفات السجل في مجلد logs

❌ مشكلة: خطأ في قاعدة البيانات
✅ الحل:
   1. تأكد من وجود مجلد database
   2. شغل error_checker_and_fixer.py
   3. امنح صلاحيات الكتابة للمجلد

📦 المتطلبات:
========================================

🐍 Python 3.8 أو أحدث
📚 المكتبات المطلوبة:
   - customtkinter (واجهة المستخدم الحديثة)
   - Pillow (معالجة الصور)
   - numpy (المعالجة السريعة)
   - matplotlib (الرسوم البيانية)

🔄 خطوات التشغيل التفصيلية:
========================================

1️⃣ التحضير:
   - تأكد من اتصال الإنترنت (لتثبيت المكتبات)
   - امنح صلاحيات المدير إذا طُلب منك

2️⃣ التثبيت:
   - شغل INSTALL_AND_RUN.bat
   - انتظر حتى انتهاء التثبيت

3️⃣ التشغيل:
   - ستظهر نافذة تسجيل الدخول
   - أدخل: admin / admin
   - استمتع بالبرنامج!
