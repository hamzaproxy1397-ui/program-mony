# 🏢 دليل تشغيل برنامج ست الكل للمحاسبة

## 📋 المتطلبات الأساسية

### 1. تثبيت Python
- اذهب إلى: https://www.python.org/downloads/
- حمل أحدث إصدار من Python (3.8 أو أحدث)
- **مهم جداً**: تأكد من تحديد "Add Python to PATH" أثناء التثبيت

### 2. تثبيت المكتبات المطلوبة
بعد تثبيت Python، افتح Command Prompt وقم بتشغيل:
```bash
pip install customtkinter pillow numpy matplotlib
```

## 🚀 طرق تشغيل البرنامج

### الطريقة الأولى: تشغيل النافذة الرئيسية مباشرة
1. انقر نقراً مزدوجاً على `launch_main_window.bat`
2. أو شغل `run_main_window.py` مباشرة

### الطريقة الثانية: تشغيل البرنامج الكامل
1. انقر نقراً مزدوجاً على `run.bat`
2. أو شغل `main.py` مباشرة

### الطريقة الثالثة: لوحة التحكم المركزية
1. انقر نقراً مزدوجاً على `START_HERE.py`
2. أو شغل الأمر: `python START_HERE.py`

## 🛠️ استكشاف الأخطاء وإصلاحها

### مشكلة: "Python not found"
**الحل**: 
1. تأكد من تثبيت Python
2. تأكد من إضافة Python إلى PATH
3. أعد تشغيل Command Prompt

### مشكلة: "Module not found"
**الحل**:
```bash
pip install --upgrade customtkinter pillow numpy matplotlib
```

### مشكلة: النافذة لا تظهر
**الحل**:
1. تحقق من شريط المهام
2. تحقق من ملفات السجل في مجلد `logs/`
3. جرب تشغيل `test_main_window.py` للتشخيص

### مشكلة: خطأ في قاعدة البيانات
**الحل**:
1. تحقق من وجود مجلد `database/`
2. تحقق من صلاحيات الكتابة
3. جرب حذف `database/accounting.db` لإعادة إنشائها

## 📞 الدعم الفني

إذا واجهت أي مشاكل:
1. تحقق من ملفات السجل في `logs/app.log`
2. جرب تشغيل `test_main_window.py` للتشخيص
3. تأكد من تثبيت جميع المتطلبات
