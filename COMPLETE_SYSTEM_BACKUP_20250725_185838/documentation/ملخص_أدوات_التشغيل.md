# 🛠️ ملخص أدوات تشغيل ومعالجة أخطاء البرنامج المحاسبي

## 🚀 ملفات التشغيل الرئيسية

### للمستخدمين العاديين:
1. **`INSTALL_AND_RUN.bat`** ⭐ **الأفضل للمبتدئين**
   - تثبيت Python تلقائياً
   - تثبيت جميع المكتبات المطلوبة
   - تشغيل البرنامج مع معالجة الأخطاء
   - واجهة تفاعلية لاختيار طريقة التثبيت

2. **`START_ACCOUNTING.bat`** 
   - تشغيل سريع للبرنامج
   - رسائل مساعدة في حالة الفشل

3. **`RUN_ACCOUNTING_SOFTWARE.bat`**
   - تشغيل البرنامج الكامل
   - فحص Python وعرض رسائل مفيدة

### للمطورين والمتقدمين:
4. **`RUN_WITH_ERROR_HANDLING.bat`**
   - فحص شامل للنظام
   - تثبيت المكتبات المفقودة
   - فحص الأخطاء النحوية
   - تشغيل مع معالجة متقدمة للأخطاء

5. **`FORCE_RUN.bat`**
   - البحث في جميع مسارات Python الممكنة
   - محاولة تشغيل حتى لو لم يكن Python في PATH

## 🔧 أدوات التشخيص والإصلاح

### أدوات Python:
1. **`quick_diagnostic.py`** ⭐ **للتشخيص السريع**
   - فحص إصدار Python
   - فحص الاستيرادات المطلوبة
   - فحص هيكل الملفات
   - اختبار استيراد الملف الرئيسي
   - إنشاء اختبار مبسط

2. **`error_checker_and_fixer.py`** ⭐ **لإصلاح الأخطاء**
   - فحص شامل لجميع ملفات Python
   - إصلاح الأخطاء النحوية الشائعة
   - تثبيت المكتبات المفقودة
   - إنشاء المجلدات المطلوبة
   - إنشاء نسخ احتياطية قبل الإصلاح

3. **`test_simple.py`** (يتم إنشاؤه تلقائياً)
   - اختبار بسيط لواجهة المستخدم
   - للتأكد من عمل customtkinter

### ملفات التشغيل المباشر:
4. **`run_main_window.py`**
   - تشغيل النافذة الرئيسية مع معالجة الأخطاء
   - رسائل مفيدة للمستخدم

5. **`test_main_window.py`**
   - اختبار شامل للنظام
   - فحص الاستيرادات والملفات

## 📚 ملفات التوثيق والمساعدة

1. **`اقرأني_أولاً.txt`** ⭐ **دليل المستخدم الشامل**
   - تعليمات التشغيل خطوة بخطوة
   - حل المشاكل الشائعة
   - نصائح للاستخدام الأمثل

2. **`دليل_التشغيل.md`**
   - دليل مفصل باللغة العربية
   - هيكل المشروع
   - بيانات تسجيل الدخول

3. **`HOW_TO_RUN.md`**
   - دليل باللغة الإنجليزية
   - للمطورين الدوليين

## 🎯 توصيات الاستخدام

### للمستخدم العادي:
1. **ابدأ بـ**: `INSTALL_AND_RUN.bat`
2. **إذا فشل**: اقرأ `اقرأني_أولاً.txt`
3. **للتشخيص**: شغل `quick_diagnostic.py`

### للمطور أو المتقدم:
1. **للتشخيص الشامل**: `error_checker_and_fixer.py`
2. **للتشغيل المتقدم**: `RUN_WITH_ERROR_HANDLING.bat`
3. **للبحث الشامل عن Python**: `FORCE_RUN.bat`

## 🔄 سير العمل الموصى به

```
1. شغل INSTALL_AND_RUN.bat
   ↓
2. إذا فشل → شغل quick_diagnostic.py
   ↓
3. إذا وُجدت أخطاء → شغل error_checker_and_fixer.py
   ↓
4. أعد تشغيل INSTALL_AND_RUN.bat
   ↓
5. إذا استمر الفشل → راجع اقرأني_أولاً.txt
```
